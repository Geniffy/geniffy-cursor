# Changelog

## 0.1.0

The first release.

- The Geniffy memory tools in Cursor, signed in with Cursor's own MCP sign-in.
- Type `geniffy login` once, and each chat starts with what Geniffy remembers about you and the project.
- Each turn is saved in the background when it ends, who said what kept, with secrets and code blocks left out.
- The memory tools that only read run without asking; saving, correcting and forgetting ask first.
- `geniffy status`, `geniffy pause`, `geniffy resume` and `geniffy logout`, typed in the chat or as commands.
